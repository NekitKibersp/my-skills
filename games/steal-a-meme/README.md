# Укради Мем (Steal a Meme 🎃)

Мультиплеерная игра жанра «steal» для Roblox. Игроки покупают мем-персонажей
на «красной дорожке», ставят их на свою базу (те приносят деньги каждую секунду) и воруют
мемов друг у друга. Идея и обоснование ниши — в [IDEA.md](IDEA.md).

Код собран Rojo и проверен линтером selene. Протестировать игру в Roblox Studio я не мог.
Если что-то не работает, пришлите красные строки из **View → Output**.

## Как открыть
1. Скачайте `StealAMeme.rbxlx` и откройте его: Roblox Studio → **File → Open from File**.
2. Нажмите **Play**. В режиме редактирования мир пустой: карта, базы и мемы создаются скриптами при запуске.
3. Чтобы проверить кражи, нужны минимум двое: **Test → Clients and Servers → 2 Players → Start**.

## Обязательные настройки перед публикацией
1. **File → Publish to Roblox** (новая игра).
2. **Game Settings → Security → Enable Studio Access to API Services**. Без этого в Studio
   не работают сохранения и лидерборды.
3. **Game Settings → Places → Server size (Max Players) = 8**. На карте 8 баз, по одной на игрока.
4. **Game Settings → Permissions → Public**, когда будете готовы открыть игру.

## Монетизация: как включить
В [src/shared/Config.luau](src/shared/Config.luau) у всех товаров (7 геймпассов и 8 продуктов) стоит `Id = 0`, то есть
товар пока выключен (в магазине будет надпись «ещё не настроен»).
1. Creator Hub → ваша игра → **Monetization → Passes**: создайте геймпассы из `Config.GamePasses`.
2. **Monetization → Developer Products**: создайте продукты из `Config.Products`.
3. Впишите их ID в `Config.GamePasses` и `Config.Products` и пересоберите плейс.
Цены в Robux задаются в Creator Hub, а в конфиге они только для показа в магазине.

## Механики
| Механика | Как работает |
|---|---|
| Дорожка | Каждые 2,2 сек из портала выходит мем. Нажал «Купить» — он летит к тебе на базу |
| Доход | Каждый мем приносит $/сек. Оффлайн игрок получает 25% дохода, максимум за 3 часа |
| Кража | На чужой базе зажми «Украсть» (1,6 сек), неси мема над головой к себе. Бежишь медленнее. Таймер 45 сек |
| Оружие | Удар отбрасывает игрока. Если тот нёс мема, мем возвращается хозяину |
| Замок | 60 сек никто не войдёт на базу (чужих выталкивает), потом 30 сек перезарядка |
| В ТРЕНДЕ | Каждые 10 мин один вид мема даёт ×3 дохода |
| Вирусность | 3 одинаковых мема (вид + мутация) сливаются в ВИРУСНОГО: ×5 дохода, освобождает 2 слота |
| Страж | Kitten with a Sword, 5 уровней. Бьёт воров, которые несут мемов с его базы |
| Ночь Smiley | Раз в 6 мин на 100 сек. Темнеет, жёлтый Smiley утаскивает мемов с открытых баз. Лучший по ударам получает редкого мема. Ночью на дорожке сезонные мемы и мутации |
| Мутации | Золотой ×1.5, Алмазный ×3. Ночью: Тыквенный ×2, Призрачный ×4 |
| Индекс | Каждая новая запись (вид + мутация) даёт +1% к доходу навсегда |
| Перерождение | Сбрасывает деньги, мемы остаются. Даёт +50% дохода навсегда, а по тирам — новые этажи базы, вращения колеса и предметы. Для каждого тира на базе должны стоять нужные мемы (их не забирают) — см. таблицу ниже |
| Этажи базы | База в 3 этажа по 12 слотов (сетка 4×3): 1-й открыт сразу, 2-й — после 1-го перерождения, 3-й — после 3-го. Наверх ведут пандусы (если смотреть от входа): на 2-й — во дворе у левой стены, сразу от входа; на 3-й — на 2-м этаже у правой стены. Закрытый этаж перекрыт розовым силовым полем «🔒 Rebirth N». Геймпасс «+слоты» добавляет ряд из 6 слотов на 1-м этаже. Новые мемы встают сначала на нижние этажи |
| Скорость | Прокачка за монеты (окно защиты), 5 уровней: +2/+4/+6/+8/+10 к скорости ходьбы — и без мема, и с мемом |
| Lucky Blocks | Редко (3%) едут по дорожке «❓ Lucky Block» Epic/Legendary/Mythic. На базе через 60 сек открываются случайным мемом своей редкости (мутация блока сохраняется). Пока закрыт — дохода нет, слить нельзя, продать можно (50%), а украсть — да: у вора таймер начнётся заново |
| Тревога | Пока вор несёт твоего мема, у тебя сирена и стрелка к вору (атрибуты StolenBy/StolenMeme) |
| «Домой» | Кнопка на HUD переносит на свою базу. Перезарядка 20 сек, с мемом в руках не работает |
| Настройки | Звук, «слабая графика», скрыть таблички над мемами, размер интерфейса (70–130%). Сохраняются |
| Награды | Ежедневная награда со стриком до 7 дней, подарки за 5/15/30/60 мин игры за день (время копится и сохраняется, перезаход их не обнуляет) |
| Лидерборды | Глобальные «Богачи» и «Воры» у точки появления (работают после публикации) |
| Предметы | Покупаются за монеты навсегда (окно 🗡️). Оружие: Тапок (бесплатно), Бита Tung Tung (отбрасывает дальше), Сковородка (оглушает на 2,5 сек), Бан-молот (бьёт всех вокруг). Гаджеты: Энергетик (+12 к скорости на 6 сек), Банановая кожура (ловушка: враг падает и роняет мема), Шапка-невидимка (8 сек, пропадает при краже или ударе) |
| Сезоны | Включаются сами по дате: Хэллоуин (1 окт – 5 ноя: тыквы, Pumpkin/Ghost мутации, хэллоуинские мемы), Зима (6 ноя – 28 фев: снег, снеговики, ёлки, Frozen/Festive мутации, зимние мемы). Вне сезонов ночью нет сезонных мемов. Включить вручную: `Config.SeasonOverride = "Winter"` |
| Туториал | Новичка ведут 4 шага со стрелкой: купить мема → доход → украсть → закрыть базу. Можно пропустить |
| Защита сохранений | Блокировка сессии: пока игрок на одном сервере, другой не загрузит его данные (нет дюпа при быстром переходе между серверами) |
| Языки | Английский и русский, язык выбирается автоматически по языку Roblox игрока. Имена персонажей всегда на английском |

## 🗺️ Зоны большой карты
Карта стала почти вдвое шире: дорожка и базы в центре, вокруг — зоны. У точки появления — **хаб телепортов**
(4 светящиеся площадки: 🗼 Башня, 🤝 Торговая площадь, 🍬 Конфетный парк, 🏠 Моя база), в каждой зоне есть
площадки «🏠 Base» и «🏪 Carpet». Телепорт — раз в 3 сек и только без мема в руках.

| Зона | Где | Как работает |
|---|---|---|
| 🗼 Башня мемов (обби) | к востоку от спавна, x≈320 | Спираль из 3 ярусов по 10 прыжков: ярус 1 — широкие платформы, ярус 2 — исчезающие стеклянные платформы и полоса лавы, ярус 3 — маленькие платформы, балка, лазанье по ферме, вращающиеся лава-перекладины. Лава под башней и на ярусах возвращает на последний чекпоинт. Призы в конце ярусов раз в день: монеты; монеты + вращение; на вершине — сундук (Epic/Legendary мем или 2 вращения + много монет). С вершины — площадка «⬇️ Back down» |
| 🤝 Торговая площадь | к западу от портала, x≈-300, z≈-60 | Безопасная зона (зелёный бордюр, плашка «🛡️ Безопасная зона»): здесь нельзя бить, стрелять, морозить и кидать бананы. Вор с мемом, зашедший сюда, роняет мема. Фонтан и 4 стола «Обмен» — открывают выбор игрока для обмена |

## Персонажи и модели
Сейчас мемы собраны из примитивов (тело + эмодзи-лицо). Настоящие модели подключаются **без кода**:

1. Откройте плейс в Studio. В **Explorer → ServerStorage** есть папка **MemeModels** (пустая).
2. Вставьте модель: из Toolbox (Creator Store), из пака, сгенерированную ИИ в Studio или импортированную (File → Import 3D).
3. **Удалите из неё все `Script`/`LocalScript`** (игра и так их вырежет, но в Studio они могут успеть сработать).
4. Перетащите модель в **ServerStorage → MemeModels** и **переименуйте её точно в Id мема** из таблицы ниже.
   Подходит Model или одиночный MeshPart. Размер не важен — игра сама подгонит высоту.
5. Play — мем с этим Id теперь выглядит как ваша модель (на дорожке, на базе, в руках у вора).
6. Если модель стоит боком/спиной — в `Config.luau` у этого мема добавьте `ModelYaw = 90` (или 180, -90).

Вариации (сезонные, лимит, эксклюзивы) без своей модели берут модель «родителя» — например, Santa 67
выглядит как Six Seven. Хотите отдельную — положите модель с Id вариации, она важнее.

⚠️ После того как положили модели, **сохраняйте плейс в Studio** (File → Save / Publish). Если пересобрать
плейс через `rojo build`, папка MemeModels снова станет пустой — чтобы этого не было, выделите папку →
правый клик → **Save to File** → `models/MemeModels.rbxm` в проекте и скажите разработчику подключить её в сборку.

## Где менять баланс
Весь баланс в [src/shared/Config.luau](src/shared/Config.luau): цены и доход мемов, шансы редкостей,
скорость дорожки, время кражи, тапок, страж, ночь, перерождения, оффлайн, подарки и товары.
Чтобы сменить сезон (Хэллоуин → Зима), замените сезонных мемов (`Event = true`) и ночные мутации.

## Что сделать дальше, чтобы игра «полетела»
1. **Модели персонажей.** Это самое важное для превью и роликов: сгенерировать в Studio
   (встроенный ИИ-генератор 3D), найти в Creator Store или заказать.
2. **Звуки:** покупка, кража, тапок, ночь. Вставляются по ID из Creator Store (сейчас звуков нет).
3. **Иконка и превью:** яркий мем крупным планом. Название вида «Steal a Meme 🎃 [NEW]».
4. **Обновления каждые 1–2 недели:** новый трендовый мем и ивент. Перед ноябрём сменить
   Хэллоуин на зимний сезон.
5. **Стартовая реклама** в Roblox Ads и ролики у Roblox-ютуберов.
