# Русская озвучка видео (edge-tts)

Скрипт `scripts/voiceover.py` синтезирует речь через edge-tts и сводит её с видео через ffmpeg.
Результат — новый .mp4 и рядом .srt с субтитрами по фразам. Исходное видео не меняется.

## Порядок работы

1. Сначала отрендерь видео (Remotion, HyperFrames и т.д.) и узнай его длительность (`ffprobe`).
2. Напиши текст озвучки под длительность: ~13–15 символов на секунду для нормального темпа
   (≈ 2 слова в секунду). Если текст длиннее — ускорь `--rate +10%`…`+20%` или сократи текст.
3. Запусти:
   ```bash
   python3 "${CLAUDE_SKILL_DIR}/scripts/voiceover.py" out/video.mp4 --text "Текст озвучки" -o out/video_voiced.mp4
   ```
   Длинный текст — в файл и `--text-file script.txt`.
4. Проверь результат: `ffprobe` длительности и наличия аудио, при возможности послушай/посмотри.

## Параметры

| Параметр | Что делает |
|---|---|
| `--voice` | голос, по умолчанию `ru-RU-DmitryNeural` (мужской). Женский: `ru-RU-SvetlanaNeural`. Список: `edge-tts --list-voices` |
| `--rate +10%` / `--pitch -5Hz` / `--volume +20%` | темп, высота, громкость синтеза |
| `--delay 0.5` | пауза перед началом речи, сек |
| `--keep-audio 0.2` | оставить исходный звук/музыку видео тихим фоном (0 — убрать) |
| `--voice-volume 1.2` | громкость голоса при сведении |
| `--fit extend` (по умолч.) / `cut` | озвучка длиннее видео: заморозить последний кадр / обрезать речь |
| `--audio voice.mp3` | наложить готовый звук без TTS |
| `--no-srt` | не писать субтитры |

## Требования

- `pip install edge-tts` (ставится `install.sh` из my-skills), `ffmpeg` и `ffprobe`.
- Доступ к `speech.platform.bing.com`. В облачной среде Claude его нужно разрешить в настройках сети;
  иначе скрипт завершится с сообщением об ошибке сети. Прокси из `HTTPS_PROXY` подхватывается сам.
- Edge TTS — бесплатный неофициальный доступ к голосам Microsoft Edge, без ключа; для коммерческих
  проектов с гарантиями лучше ElevenLabs (скилл `text-to-speech`).
