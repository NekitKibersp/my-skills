# Титульный лист для учебных работ

Постоянные данные студента лежат в `student.json` рядом с этим файлом (колледж, ФИО, курс, группа,
квалификация, город). Год ставится текущий автоматически. Вёрстка повторяет образец пользователя:
Times New Roman 14, интервал 1,5; сверху по центру министерство и колледж; по центру тип работы
заглавными, «по дисциплине», «Предмет» в кавычках, «на тему: «…»», «Квалификация: Программист»;
справа блок «Выполнил: / Медведев Н.О. / Студент: N курса / Группы: … / Руководитель: / Фамилия И.О.»;
внизу по центру «Донецк» и «2026 год».

## Что спросить у пользователя

Каждый раз спросить одним сообщением (то, что уже известно из разговора или задания, не переспрашивать):
1. **Название предмета** (дисциплины или модуля, например «Технология разработки программного обеспечения»).
2. **Преподаватель** — ФИО; скрипт сам сократит до «Фамилия И.О.».
3. **Тема работы.**

Тип работы (РЕФЕРАТ, ОТЧЕТ, КУРСОВАЯ РАБОТА, ДОКЛАД…) берётся из задания; если неясно — тоже спросить.
Для отчёта по практике вторая строка не «по дисциплине», а например «По учебной практике» (`--discipline-label`).

Если в `student.json` поле `group` равно `null` или курс явно устарел (новый учебный год с 1 сентября) —
спросить у пользователя, обновить `student.json` в репозитории my-skills, закоммитить и запушить в `main`.

## Как сделать

Нужен `python-docx` (`pip install python-docx`, если нет).

Отдельный файл с титульным:
```bash
python3 ~/.claude/skills/title-page/scripts/make_title.py \
  --type "Реферат" --subject "Технология разработки программного обеспечения" \
  --teacher "Близкая Ольга Владимировна" --topic "Система контроля версий Git" \
  --out Титульный.docx
```

Вставить титульный первой страницей в готовую работу (на титульном номер страницы не ставится,
после него разрыв страницы):
```bash
python3 ~/.claude/skills/title-page/scripts/make_title.py ... --into Работа.docx --out Работа_с_титульным.docx
```
Если в работе уже есть свой титульный лист — сначала удалить его, потом вставлять.

Любое поле из `student.json` можно переопределить флагом: `--student`, `--course`, `--group`, `--college`,
`--qualification`, `--city`, `--year`.

## Проверка

Сконвертировать в PDF (`soffice --headless --convert-to pdf`), посмотреть первую страницу картинкой
(`pdftoppm -r 50 -f 1 -l 1 -png`): титульный должен занимать ровно одну страницу, «Донецк / год» внизу,
без номера страницы. Если поля работы сильно отличаются и всё съехало на вторую страницу — уменьшить
количество пустых строк в `build_lines()` (скрипт) или передать готовой работе свои поля.
