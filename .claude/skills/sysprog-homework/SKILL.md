# Системное программирование: код + отчёт

Пользователь (студент, Медведев Н.О.) получает задания по системному программированию. Нужно сдать:
**проекты Visual Studio (C++) + отчёт .docx**, всё в одной зипке, «точь-в-точь» как прошлые работы.
Код — максимально простой, «студенческий», без лишних классов и проверок.

## Порядок работы

1. **Задание.** Обычно приходит фото экрана с текстом заданий. Переписать каждое задание дословно —
   эти формулировки идут в отчёт после «Задание N.». Если тему на фото не видно, придумать по смыслу
   и в конце предупредить, что её надо сверить.

2. **Образец (зипка с прошлой работой).** Большие файлы пользователь кидает ссылкой на Яндекс Диск.
   Скачать и распаковать в пустую папку в scratchpad (мусор сборки `x64/Debug/.vs` скрипт пропускает,
   имена cp866 чинит):
   ```bash
   python3 -I scripts/fetch_zip.py "https://disk.yandex.ru/d/..." "$SCRATCH/dl"
   ```
   Прочитать все `.cpp` и текст отчёта (`unzip` docx → `word/document.xml`) — повторять стиль кода
   и структуру отчёта именно оттуда, если она изменилась относительно описанной ниже.
   Если ссылки нет и образец уже разобран ниже — можно делать без зипки.

3. **Код** — по одному файлу на задание, стиль как у пользователя:
   - `#include <iostream>`, `<string>`, `<fstream>`… и `#include <windows.h>`;
   - в начале `main`: `SetConsoleCP(1251);` и `SetConsoleOutputCP(1251);` (русский в консоли);
   - `std::` перед всем, без `using namespace std;`, табы для отступов;
   - сообщения на русском, простые (`"Введите пароль: "`, `"Ошибка: "`);
   - для заданий «ввод до правильного» — цикл `while (true)`, чтобы на скрине было видно все проверки;
   - без комментариев-простыней и без «защиты от всего»: преподавателю нужно увидеть суть.
   Проверить, что собирается и работает (заглушка `windows.h` для Linux лежит в шаблоне):
   ```bash
   scripts/check_cpp.sh task1.cpp 'ввод1\nввод2\n'
   ```
   Для настоящего WinAPI (хуки `SetWindowsHookEx`, `CreateProcess`, `CreateThread`, `GetMessage`)
   заглушка не подойдёт — допиши нужные объявления в копию заглушки или честно скажи, что проверено только чтением.

4. **Проекты VS** — из шаблона (Visual Studio 2026, `.slnx`, x64, v145), имена `ConsoleApplication1`, `ConsoleApplication2`…:
   ```bash
   scripts/new_vs_project.sh "$OUT/<Название работы>" ConsoleApplication1 task1.cpp
   ```
   `.cpp` сохраняется в UTF-8 с BOM и CRLF, как делает сама VS (без BOM русские строки сломаются).

5. **Скриншоты консоли.** Записать в txt то, что будет видно в консоли (ввод пользователя в той же строке,
   что и приглашение), и нарисовать:
   ```bash
   python3 scripts/console_shot.py shot1.png ConsoleApplication1 out1.txt
   ```
   Вывод брать из реального запуска `check_cpp.sh`, а не выдумывать. **Всегда предупреждать**, что скрины
   нарисованы и лучше заменить своими (Ctrl+F5 в VS → скрин окна консоли).

6. **Отчёт** — `spec.json` (формат в начале `scripts/build_report.py`) и:
   ```bash
   python3 scripts/build_report.py spec.json "$OUT/<Название работы>/Медведев Отчет.docx" [свежий_образец.docx]
   ```
   Проверить: `soffice --headless --convert-to pdf` → `pdftoppm -r 50 -png` → посмотреть страницы.

7. **Зипка** — папка `<Название работы>/` с проектами и отчётом → `zip -r`, отправить пользователю
   (SendUserFile) зипку и отдельно docx. В ответе коротко: что в каждом задании, что проверить (скрины, тема).

## Формат отчёта (по образцу «Медведев Отчет.docx»)

**Титульного листа нет** (пользователь сказал «титульник не надо» для этого предмета — скилл `title-page` здесь не нужен,
если пользователь сам не попросит). Times New Roman 14, выравнивание по ширине, одинарный интервал,
поля: левое 30, правое 15, верх/низ 20 мм. Структура:

```
Домашнее задание                         ← жирный
                Тема: <Тема>.            ← отступ слева 2,5 см + красная строка
Задание 1. <формулировка дословно>       ← «Задание 1.» жирным, дальше обычный
Код:
<код построчно, обычный Times New Roman 14, каждая строка — отдельный абзац>
(пустая строка)
<скриншот консоли во всю ширину>
Рис. 1 Консольное приложение с <чем>     ← курсив 12, по центру
(пустая строка)
Результат: Мы научились писать программу, которая <что делает>.
(пустая строка)
Задание 2. ... (так же)
```

Подпись рисунка всегда начинается с «Консольное приложение с …», «Результат» — с «Мы научились …».

## Частые вопросы по Visual Studio

- **«Открыл проект, а кода не видно»** — студия не открыла файл. Вид → Обозреватель решений (Ctrl+Alt+L) →
  проект → Исходные файлы → двойной щелчок по `.cpp`. Студия запомнит вкладку в скрытой папке `.vs`.
  Открывать нужно файл `.slnx`.
- **Консоль сразу закрывается** — запускать через Отладка → Запуск без отладки (Ctrl+F5).
- **Кракозябры вместо русского** — нет `SetConsoleCP/SetConsoleOutputCP(1251)` или `.cpp` не в UTF-8 с BOM.
- **Хук `WH_KEYBOARD_LL` ловит коды клавиш, а не буквы** — `vkCode` латиницы совпадает с заглавной буквой,
  поэтому сравнивать с `"QWERTY"`; для работы хука нужен цикл `GetMessage`.
