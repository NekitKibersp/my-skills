# Рецепты жанров

Для каждого жанра: игровой цикл, данные для сохранения, сервисы, грабли.
Цифры — стартовые; держите их в `Config.luau`.

## Симулятор (кликер/добыча)
Полная реализация: `examples/crystal-simulator/`.

- **Цикл:** добыть ресурс → рюкзак полон → продать → купить инструмент/рюкзак → открыть зону → переродиться.
- **Данные:** Coins, Ore, ToolTier, BackpackTier, MaxZone, Rebirths, TotalOre.
- **Сервисы:** DataService, MapBuilder, MiningService (инструмент + узлы ресурса), ShopService (продажа, покупки, зоны, перерождение).
- **Баланс:** цена следующего уровня ×7–8, сила ×2.5–3; вместимость рюкзака — главный ограничитель, она должна отставать от силы инструмента. Зона ×4–15 к награде. Перерождение: цена ×2.5, +0.5 к множителю.
- **Грабли:** проверка дистанции и кулдауна на сервере; ворота зон — коллизия выключается на клиенте (своя физика персонажа), доступ к ресурсам зоны проверяет сервер.

## Обби
- **Цикл:** пройти этап → чекпоинт → следующий этап; время/смерти в лидерборде.
- **Данные:** Stage (максимальный этап), BestTime, Deaths. Скипы этапа — Developer Product.
- **Сервисы:** DataService, ObbyBuilder (генерирует этапы кодом), CheckpointService.
- **Чекпоинты:** `Touched` на плите этапа N засчитывается только если `N == Stage + 1` (нельзя перепрыгнуть). На `CharacterAdded` ставить персонажа: `character:PivotTo(checkpoint.CFrame + Vector3.new(0, 4, 0))` после `character:WaitForChild("HumanoidRootPart")`.
- **Убивающие блоки:** `Touched` → `humanoid.Health = 0`. Красный Neon, имя `Kill`.
- **Препятствия:** вращающиеся балки (`HingeConstraint` с мотором или анкерная деталь + `TweenService` по CFrame на сервере), исчезающие плиты (Transparency/CanCollide по таймеру), движущиеся платформы (`PrismaticConstraint` или `AlignPosition` — анкерные детали, двигаемые твином, не везут игрока).
- **Сложность** растёт с номером: ширина плит ↓, расстояние ↑.
- **Грабли:** чекпоинт засчитывается и для мёртвого персонажа — проверяйте `humanoid.Health > 0`.

## Тайкун
- **Цикл:** дропперы роняют детали → конвейер везёт в сборщик → деньги → кнопки покупки открывают следующие объекты.
- **Данные:** Cash, список купленных кнопок (`{ [buttonId] = true }` → сохранять таблицу, расширить DataService), Rebirths.
- **Сервисы:** PlotService (выдаёт участок свободному игроку, освобождает при выходе), TycoonService (кнопки, дропперы, сборщик).
- **Кнопки:** конфиг `{ Id, Price, Unlocks = "Dropper1", Requires = "Wall1" }`; кнопка видна, когда куплено `Requires`. Объекты участка хранятся шаблоном в `ServerStorage`, клонируются при покупке.
- **Дропперы:** `task.spawn` цикл, деталь с атрибутом `Value`; сборщик по `Touched` начисляет владельцу участка и уничтожает деталь. Лимит деталей на участке (например 60), иначе лаги.
- **Конвейер:** `part.AssemblyLinearVelocity = direction * speed` на анкерной детали.
- **Грабли:** участок должен знать владельца (`plot:SetAttribute("OwnerUserId", ...)`), иначе чужие кнопки покупаются. При выходе — очистить участок и вернуть в пул.

## PvP-арена на раунды
- **Цикл:** лобби → интермиссия (N секунд, нужно ≥2 игроков) → телепорт на арену → бой до таймера/последнего живого → награда → лобби.
- **Данные:** Coins, Wins, Kills; купленное оружие.
- **Сервисы:** RoundService (машина состояний: `Waiting`, `Intermission`, `InRound`, `Ended`), WeaponService, DataService.
- **Состояние раунда** храните в `ReplicatedStorage` атрибутах (`State`, `TimeLeft`) — UI читает их без remotes.
- **Оружие ближнего боя:** урон считает сервер: на `Tool.Activated` — `workspace:GetPartBoundsInBox` перед игроком или `Touched` клинка во время окна удара; кулдаун на сервере; не бить своих/уже мёртвых.
- **Стрельба:** клиент шлёт направление (`Remote:FireServer(origin, direction)`), сервер проверяет кулдаун, что `origin` рядом с головой игрока, делает `workspace:Raycast` сам. Никогда не принимайте от клиента «кого я убил».
- **Убийства:** при попадании записывайте `humanoid:SetAttribute("LastHitBy", player.UserId)`; в `Humanoid.Died` начисляйте убийство этому игроку.
- **Грабли:** игрок вышел посреди раунда; все умерли одновременно; раунд при 1 игроке — обрабатывайте каждый случай.

## Tower defense
- **Цикл:** волна врагов идёт по пути → игрок ставит башни на клетки → убийства дают деньги → следующая волна сильнее.
- **Путь:** точки `Waypoints` (папка частей с номерами); враги — модели, движение сервером через `humanoid:MoveTo` по точкам или твин `PivotTo` (дешевле для многих врагов).
- **Башни:** сервер ищет цель в радиусе каждые `Config.Tick` секунд, сам наносит урон. Размещение: клиент присылает id клетки, сервер проверяет деньги и занятость.
- **Грабли:** сотни врагов-гуманоидов тормозят — для массовки используйте анкерные модели без Humanoid и храните HP в атрибуте.

## Хоррор / история
- **Цикл:** исследование → задачи (ключи, генераторы) → монстр преследует → побег.
- **Монстр:** `PathfindingService:CreatePath()`, пересчёт пути раз в 0.5–1 с к ближайшему видимому игроку (`workspace:Raycast` для линии взгляда); `SetNetworkOwner(nil)` для его частей.
- **Атмосфера:** `Lighting.ClockTime = 0`, `Atmosphere.Density` 0.5+, фонарик — `SpotLight` в инструменте; звуки шагов и дыхания.
- **Грабли:** скримеры только на клиенте (камера, звук), события — по сигналу сервера.
