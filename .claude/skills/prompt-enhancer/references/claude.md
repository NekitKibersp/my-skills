# Промпт для Claude (и других сильных ассистентов-агентов)

Хороший промпт для Claude — как задание толковому новому сотруднику: он умный, но не знает контекста.

## Каркас

```
## Цель
<что сделать и ЗАЧЕМ — зачем важно не меньше, чем что: это помогает принимать решения в деталях>

## Контекст
<для кого результат, где будет использоваться, что уже есть (файлы, ссылки, прошлые решения)>

## Требования
- <обязательное 1>
- <обязательное 2>
<конкретно: объём, язык, стиль, технологии, ограничения — «не трогай X», «без внешних библиотек»>

## Результат
<в каком виде сдать: файл .pptx / код в репозитории / таблица / текст N слов; куда положить>

## Готово, когда
<как проверить: «открывается в Studio и игра запускается», «все тесты проходят», «влезает на 10 слайдов»>
```

Секции, которые нечем заполнить, опускай. Для простой задачи достаточно 3–5 предложений.

## Приёмы
- **Зачем + для кого** резко улучшают результат: «курсовая для 2 курса колледжа по методичке» ≠ «статья».
- **Примеры** желаемого результата (или «в стиле X») — лучше длинных описаний.
- **Критерии готовности** превращают «сделай хорошо» в проверяемое.
- **Что важнее при конфликте**: «если не влезает — сокращай примеры, а не теорию».
- Для больших задач: «сначала план, покажи мне, потом делай» — если пользователь хочет контролировать.
- Не пиши «ты — эксперт мирового уровня»: ролевые заклинания почти не помогают, контекст помогает.
- Не используй КАПС и «ОБЯЗАТЕЛЬНО!!!» — спокойная формулировка с причиной работает лучше.

## Пример
Было: «сделай презентацию про космос»
Стало:
```
## Цель
Презентация про Солнечную систему для выступления на уроке, 7 минут. Нужно, чтобы одноклассники
(8 класс) не заскучали и запомнили 3–4 ярких факта.

## Требования
- 10–12 слайдов, на каждом не больше 2–3 коротких тезисов, крупные картинки
- Порядок: Солнце → планеты по удалённости → интересные факты → итог-викторина из 3 вопросов
- Язык простой, без формул; цифры только впечатляющие и понятные («в Юпитер влезет 1300 Земель»)
- В заметках докладчика — что говорить на каждом слайде (2–3 предложения)

## Результат
Файл .pptx, тёмная «космическая» тема.

## Готово, когда
Открывается в PowerPoint, текст не вылезает за края, есть заметки к каждому слайду.
```
