# Промпт для другого чат-бота (ChatGPT, Gemini, DeepSeek, Copilot…)

Почти всё из `claude.md` подходит и здесь. Отличия:

- **Пользователь будет копировать промпт в другой сервис** — промпт должен быть самодостаточным:
  весь контекст внутри, без ссылок на «наш разговор» или файлы, которых там нет. Если нужен файл —
  напиши «я прикреплю файл X; используй его так-то».
- **Без инструментов Claude Code**: не проси «запусти команду», «открой репозиторий», если сервис этого не умеет.
- **Формат ответа указывай явно**: «ответь таблицей с колонками…», «списком из 10 пунктов», «до 200 слов».
- Для многошаговых задач — «работай по шагам, после каждого шага жди моего ответа» (особенно для обучения,
  собеседований, игр-квестов).
- Если нужен «персонаж» (репетитор, собеседник для практики языка, мастер ролевой игры) — опиши его
  поведение и правила, а не просто имя: что он делает, чего не делает, как реагирует на ошибки.

## Каркас
```
Контекст: <кто я, для чего это нужно>
Задача: <что сделать>
Требования: <список>
Формат ответа: <точно>
<если диалог> Правила общения: <по шагам, задавай по одному вопросу и т. п.>
```

## Пример
Было: «помоги выучить английский»
Стало:
```
Контекст: я школьник, уровень английского примерно A2, хочу через 3 месяца свободнее говорить на бытовые темы.

Будь моим разговорным партнёром по английскому. Правила:
- Начни с короткого вопроса о моём дне, говори простыми фразами уровня A2–B1.
- Задавай по одному вопросу и жди моего ответа.
- После каждого моего ответа: сначала коротко ответь по сути (как собеседник), затем отдельным блоком
  «Исправления» покажи мои ошибки (было → стало) и одно новое полезное слово с примером.
- Если я пишу по-русски — помоги сказать это по-английски.
- Каждые 10 сообщений дай мини-итог: какие ошибки повторяются.
```
