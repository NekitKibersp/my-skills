# Prompt Enhancer: из короткой идеи — сильный промпт

Пользователь даёт короткую идею («картинка: кот-самурай», «сделай презентацию про космос»).
Твоя задача — превратить её в подробный промпт, который даст хороший результат с первого раза.
Не выполняй саму задачу, пока пользователь не попросит: результат этого скилла — промпт.

## 1. Определи цель

| Цель | Признаки | Справочник |
|---|---|---|
| **Claude** (выполнить здесь) | задача для тебя: код, текст, презентация, игра, анализ | `references/claude.md` |
| **Картинка** | «картинка», «арт», «логотип», Midjourney, Nano Banana, DALL-E, Flux | `references/image.md` |
| **Видео** | «видео», «ролик», Sora, Veo, Kling, Runway | `references/video.md` |
| **Музыка / голос** | «песня», «трек», «озвучка», Suno, Udio, ElevenLabs | `references/audio.md` |
| **Другой чат-бот** | ChatGPT, Gemini, DeepSeek, «промпт для нейросети» | `references/chatbot.md` |

Если цель неясна — спроси одним вопросом. Открой только нужный справочник.

## 2. Уточни, если не хватает главного

Задай **не больше 3 вопросов** и только о том, что сильно меняет результат и что нельзя разумно
додумать: для кого, где будет использоваться, стиль/настроение, объём или формат. Давай варианты ответа.
Если пользователь сказал «без вопросов» или идея и так понятна — не спрашивай, додумай сам и
перечисли свои допущения одной строкой.

## 3. Собери промпт

Общие правила для любой цели:
- **Конкретика вместо оценок.** Не «красивый», а что именно делает красиво: свет, цвет, композиция, материал.
- **Сохрани замысел.** Всё, что пользователь назвал, обязательно в промпте; додумываешь только детали.
- **Одна главная мысль.** Не перегружай противоречащими требованиями; второстепенное — короче.
- **Язык промпта:** для генераторов картинок/видео/музыки — английский (они понимают его лучше),
  для Claude и чат-ботов — язык пользователя, если не просили иначе. Тексты, которые должны появиться
  в результате (надписи, слова песни), — на нужном языке, в кавычках.
- **Длина по цели:** картинка — 1–3 насыщенных абзаца или 40–120 слов; видео — по сценам;
  Claude/чат-бот — сколько нужно, но структурировано.

## 4. Выдай результат

Формат ответа:

1. **Промпт** — в блоке кода, чтобы удобно скопировать. Для генераторов — отдельно параметры
   (соотношение сторон, длительность, negative prompt), если сервис их поддерживает.
2. **Что я добавил** — 2–4 пункта простым языком: какие детали додумал и зачем.
3. **Варианты** (по желанию, для картинок/видео/музыки) — 1–2 альтернативы в другом стиле, коротко.
4. Для цели «Claude» — спроси: «Выполнить?» Если пользователь соглашается — выполняй именно этот промпт.

## Расширение уже готового промпта

Если пользователь прислал свой промпт и просит улучшить:
- найди, чего не хватает (цель, контекст, формат, критерии готовности, стиль, ограничения);
- убери воду и противоречия;
- покажи улучшенную версию и коротко — что изменил. Не меняй смысл без спроса.
