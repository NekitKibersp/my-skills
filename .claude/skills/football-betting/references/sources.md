# Где брать данные

Проверено из облачной сессии Claude Code (ноябрь 2026): «работает» — страница отдаётся обычным запросом
(curl / WebFetch), «блок» — защита от ботов (Cloudflare), нужен браузер или другой источник.
С домашнего компьютера часть «блоков» может открываться через браузерный скилл (`anthropic-skills:chrome-browser`),
но не всегда.

Если сайт заблокирован — используй WebSearch: в сниппетах поиска часто есть нужные цифры
(«<команда> угловые в среднем за матч 2026», «<судья> желтые карточки в среднем»). Указывай источник каждой цифры.

## API с ключом (надёжнее парсинга)
- **API-Football** (api-football.com / v3.football.api-sports.io): матчи, составы, травмы, статистика матча
  (угловые, ЖК), коэффициенты, судьи. Бесплатно ~100 запросов/день. Ключ в заголовке `x-apisports-key`.
- **The Odds API** (the-odds-api.com): коэффициенты десятков букмекеров (в основном зарубежных), бесплатно ~500 запросов/мес.
- **football-data.org**: бесплатный ключ, `X-Auth-Token`.

В облачной сессии ключ просить через инструмент `request_credential` (не в чате). Дома — переменная окружения
(`$env:APISPORTS_KEY = "..."` в PowerShell), в репозиторий ключи не класть.

## Сколько запросов делать
Немного: читать страницы матча вручную, а не выкачивать сайты целиком. Массовый парсинг нарушает правила сайтов
и приводит к блокировке IP.
